# Остатки WB — сайт

Остатки товаров Wildberries по категориям и ярлыкам, выгрузка в Excel и объединение карточек.

**Всё работает прямо в браузере.** Токен WB и загруженные данные хранятся только в браузере
пользователя и отправляются только в WB (WB разрешает такие запросы с любого сайта).
Сервера нет: сайт — это набор статических файлов, его можно разместить на GitHub Pages.

## Что умеет
- **Остатки** — как колонка «Остаток» в «Товары и цены» (отчёт «Остатки» Аналитики WB, все склады).
  Выбор категории и ярлыков, по умолчанию только остаток больше нуля.
- **Excel** — лист «Остатки», у каждого ярлыка блок «Артикул / Кол-во»; в алмазной мозаике,
  картинах по номерам и вышивке — «Артикул / Название / Кол-во». Шапка 4472C4, подзаголовок D9E1F2,
  рамки, «Итого SKU» с формулой COUNTA.
- **Карточки** — объединение товаров по списку (текстом или из Excel): проверка, план «сейчас → станет»,
  выполнение способом «якоря», перепроверка в WB, снимок «как было» и откат.
- **Несколько магазинов** — каждый пользователь добавляет свои.

## Как получить токен WB
Кабинет WB → «Профиль» → «Настройки» → «Доступ к API» → «Создать токен».
Категории: **Контент** и **Аналитика**. Для одних остатков и Excel можно отметить «Только чтение»;
для объединения карточек — без «Только чтение».

## Для разработчика
- Код: `index.html`, `css/`, `js/` (ES-модули), `vendor/exceljs.min.js` (ExcelJS 4.4.0, MIT).
- Логика перенесена из Mac-приложения «Остатки WB» (Python) и сверена с ним на реальных данных:
  отчёты, названия, Excel ячейка в ячейку, план объединения.
- Тесты: `npm install`, затем `npm test`.
- Локальный просмотр: `npm run serve` и открыть http://127.0.0.1:8790
